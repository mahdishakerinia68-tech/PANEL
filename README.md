# STRIX VIP PANEL v1.5

### First-time admin setup
در اولین اجرای Backend هیچ نام کاربری یا رمز ادمین پیش‌فرضی وجود ندارد.
صفحه ساخت اولین ادمین نمایش داده می‌شود.

قوانین:
- نام کاربری توسط خودت تعیین می‌شود.
- رمز عبور حداقل ۸ کاراکتر است.
- فقط وقتی هیچ ادمینی در دیتابیس وجود نداشته باشد، ساخت اولین ادمین ممکن است.
- بعد از ساخت اولین ادمین، ورود عادی فعال می‌شود.
- ادمین‌های بعدی فقط از داخل بخش «مدیران» ساخته می‌شوند.

برای اجرا:
1. داخل `backend` دستور `npm install`
2. فایل `.env.example` را به `.env` تبدیل و `JWT_SECRET` را مقداردهی کن.
3. `npm start`
