# MARZ Master Panel v1 — Multi-Tenant
نسخه ۱.۱ شامل ساختار چندمشتری در Frontend است:
- مدیر اصلی
- ساخت مشتری پنل
- ورود جداگانه مشتری
- جداسازی کاربران، سرویس‌ها و پلن‌های هر مشتری با customerId
- ویرایش و حذف در بخش‌های اصلی
- پلن‌ها در شروع خالی هستند

حساب دموی مدیر: admin / admin
حساب دموی مشتری: customer / customer

این نسخه هنوز Backend واقعی ندارد. برای استفاده واقعی، احراز هویت و جداسازی داده باید در Backend + Database انجام شود و رمزها/توکن‌های Marzban هرگز در GitHub Pages قرار نگیرند.
